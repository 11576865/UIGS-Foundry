# Candidate: Workflow-centric UI acceptance must preserve simultaneous task context

Date: 2026-10-04
Status: Candidate
Scope: professional editing interfaces, spatial workspaces

## Observation

A professional UI can expose every required feature and still fail practical use if a continuous task is fragmented across mutually exclusive screens, repeated mode switching, or context loss.

A real subtitle-authoring workflow requires video inspection, timing evidence, frame stepping, cue boundary edits, text editing, merge/split, role assignment, style operations, and undo to cooperate as one task chain.

## Candidate rule

Evaluate professional interfaces with an end-to-end workflow acceptance scenario, not only a feature checklist.

For operations that belong to one continuous decision loop:

- keep the critical evidence needed for the next decision simultaneously visible or immediately glanceable;
- avoid full-page navigation when an adjacent operation can be expressed locally;
- preserve current selection, playhead/time, edit target, and relevant visual context across nearby operations;
- distinguish persistent context from secondary one-action context and infrequent recoverable tools instead of forcing every capability on screen at once;
- count repeated UI switching, context reconstruction, and surface management as interaction cost.

An interface should not be considered successful merely because every capability is reachable.

## Evidence boundary

Derived from a concrete tablet subtitle-authoring acceptance scenario. Exact visibility budgets, panel arrangements, and interaction-count thresholds remain product-specific.

Do not promote to Canonical from this observation alone.
