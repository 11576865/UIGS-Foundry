# Bug Museum

Bug Museum stores concrete failures that actually occurred or were directly reproduced.

A Bug record should answer:
- what visibly failed;
- the real root cause, if known;
- why the failure was plausible;
- what fixed it;
- what regression guard now prevents recurrence;
- what broader reusable lesson can be extracted.

Do not turn every hypothetical risk into a Bug. Hypothetical risks belong in test patterns, failure-prevention checklists, or Candidates.
